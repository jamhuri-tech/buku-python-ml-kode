## Mengerjakan di Kaggle atau Colab

1. Unduh satu notebook, atau ekstrak paket ZIP terlebih dahulu.
2. Impor file `.ipynb` ke notebook Python. Gunakan CPU; dataset latihan disediakan
   di dalam notebook dan tidak perlu diunduh terpisah.
3. Isi identitas dan prediksi sebelum menjalankan contoh.
4. Jalankan sel dari atas ke bawah. Sel persiapan dan fungsi pemeriksa cukup dijalankan.
5. Lengkapi sel **[ISI KODE]**. Jalankan definisi yang diperbaiki, kemudian sel
   **[CEK OTOMATIS]** setelahnya.
6. Isi **Refleksi akhir**, lalu mulai ulang sesi dan jalankan seluruh sel sebelum
   mengumpulkan file `.ipynb`.

**BELUM DIISI** adalah status awal yang disengaja. Status belum lulus atau
**PERLU PERBAIKAN** menunjukkan hasil yang belum sesuai kasus uji. **GALAT**
menyebut exception yang perlu diperiksa. **LULUS** berarti kasus uji yang
tersedia sudah terpenuhi, bukan bukti untuk seluruh kemungkinan input.

Pengujian terbuka dapat dibaca mahasiswa. Sel jawaban masih berupa kerangka,
sementara contoh pembelajaran tetap tersedia. Kunci asisten tidak diterbitkan.

## Keterbacaan kode dan refleksi

Satu sel definisi memuat satu fungsi mandiri atau satu kelas; pemanggilannya
terpisah. Metode dalam satu kelas dan fungsi bersarang tetap disatukan karena
merupakan satu kesatuan Python. Spasi, indentasi, dan baris kosong sudah
dirapikan. Sel kode terpanjang pada rilis ini memuat 28 baris.

**Refleksi akhir** membantu Anda merangkum pemahaman, menjelaskan penyebab
kesalahan, dan mengusulkan kasus uji tambahan. Tuliskan pengalaman percobaan
dengan kalimat sendiri. Bagian ini bukan perintah program untuk menutup notebook.

## Menjalankan lokal

Dari direktori utama repositori, gunakan lingkungan Python 3.10 atau lebih baru:

```bash
python3 -m venv .venv-praktikum
source .venv-praktikum/bin/activate
python -m pip install -r praktikum/requirements.txt
jupyter lab praktikum/
```

Pada Windows, aktivasi lingkungannya adalah `.venv-praktikum\Scripts\activate`.
Kaggle dan Colab tidak membaca `requirements.txt` secara otomatis; sel persiapan
menampilkan versi pustaka yang digunakan.
